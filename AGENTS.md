# AGENTS.md

## What this is

C++14 GUI tool (SDL2 + ImGui) for converting images to ZX Spectrum / retro-platform formats. Extended with video processing via ffmpeg pipes, CLI batch mode, pipe mode, and video keyframes with interpolation.

## Version

Current: **5.5** (defined as `#define VERSION "5.5"` in `src/main.cpp:61`).

## Build

### CMake (cross-platform)
```bash
mkdir build && cd build
cmake ..
make
```
Dependencies: SDL2, OpenGL. On Linux also GTK3; on macOS AppKit.

### Visual Studio (Windows)
Open `build/Img2Spec.sln` (generated by CMake). Uses VS2022 toolset. x64 Release config. SDL2 expected at `libraries/sdl2/`.

### MinGW cross-compile (Linux → Windows)
```bash
./build_w32.sh   # i686, static
./build_w64.sh   # x86_64, static
```
Requires `mingw-w64-cmake` (e.g. Arch AUR).

## Source layout

- `src/main.cpp` — **monolithic entry point** (~3200 lines). All logic lives here: CLI parsing, GUI, video pipeline, export, pipe mode, keyframes.
- `src/*.h` — header-only device and modifier implementations. No `.cpp` files besides `main.cpp` and platform shims.
- `src/imgui/` — vendored Dear ImGui (with SDL2 backend).
- `src/parson/` — vendored JSON parser (workspace serialization).
- `src/stb/` — vendored stb libraries (image load/write/resize).
- `src/platform/` — platform shims for file dialogs (`win32.cpp`, `nonwin32.cpp`).
- `img/` — screenshots for README (main-window.png, keyframes-ui.png, export-window.png).
- `README.md` — English documentation.
- `README_ru.md` — Russian documentation.

## Key architecture facts

- **Devices** (`src/device.h`): abstract interface for target formats (ZX Spectrum, ZX 3x64, C64 HiRes, C64 Multicolor). Each device is a header-only class.
- **Modifiers** (`src/modifier.h`): stackable image processing pipeline. Each modifier is header-only, has `ui()`, `process()`, `serialize()`, `deserialize()`. 14 modifiers total: ScalePos, Quantize, Ordered Dither, Error Diffusion Dither, Edge, Blur, Min/Max, HSV, YIQ, RGB, Contrast, Curve, Noise, SuperBlack.
- **Workspace files** (`.isw`): JSON files via parson. Save/load all device + modifier state. Uses dot-notation (`json_object_dotset_number`).
- **Pipe mode** (`--pipe`): reads raw RGB24 frames from stdin, processes through device + modifiers, writes RGBA to stdout. Frame size determined by `--width` / `--height` or device resolution.
- **Video export**: triple-pipe chain: `ffmpeg (decode) → img2spec --pipe (process) → ffmpeg (encode)`. Runs in a batch file on Windows. Progress parsed from ffmpeg `-progress` output.
- **`--batch-stdin`**: reads JSON lines from stdin for batch image processing.
- **Video keyframes** (`src/main.cpp:129-142`): `VideoKeyframe` struct with `int frame` + `JSON_Value* snapshot`. Stored in `gKeyframes[4096]`. Auto-capture on parameter change. Hold semantics (apply until next keyframe). Sidecar file: `<video>.keyframes.json`.
- **Keyframe interpolation** (`--interpolate`): JSON numeric lerp between keyframe snapshots. Falls back to step when device types or modifier stacks differ. Enabled via checkbox or CLI flag.
- **Serialization helpers**: `serialize_snapshot_to_json()` and `deserialize_snapshot_from_json()` used by workspace save/load, video export, and keyframe system.

## Gotchas

- `IMGUI_INCLUDE_IMGUI_USER_INL` must be defined at compile time (CMakeLists.txt and vcxproj both set it).
- ffmpeg must be in PATH or in the program folder for video export.
- `--headless` appears in the README but is **not implemented** in code — do not reference it as functional.
- No tests, no lint, no CI. Verify changes by building and running manually.
- Commit messages mix English conventional prefixes (`docs:`, `chore:`) with Russian descriptions.
- Static linking for MinGW cross-builds (`-static` in cmake flags).
- Output binary is `img2spec_video.exe` (both CMake and vcxproj). Renamed from original `img2spec` to distinguish the fork.
- **ImGui SliderInt format string**: `SliderInt` internally converts to float and calls `SliderFloat`, which formats via `ImFormatString(buf, ..., display_format, *v)` where `*v` is float. Using `%d` is **undefined behavior** (float passed where int expected). Always use `%.0f` for integer-like display of slider values.
- **`get_video_frame()` is blocking**: spawns ffmpeg subprocess and reads raw frames synchronously. Must not be called inside ImGui widget callbacks (causes UI freeze). Use pending frame mechanism (`gVideoPendingFrame`) to defer loading after `ImGui::Render()`.
- **`gVideoCurrentFrame`**: set at the start of `get_video_frame()` before any early returns, so it updates even on pipe failure.
- **JSON dot-notation**: all modifier params serialize as numbers via `json_object_dotset_number` with dot-notation (e.g. `Stack.mStrength`). Bool and enum fields (mEnabled, Type, gDeviceId) also serialize as numbers.
- **Release builds**: copy `img2spec.exe` + `SDL2.dll` from `build/Release/` and `libraries/sdl2/` respectively. Release folder naming convention: `YYYY-MM-DD_vX.Y/`.
